## 🤖 Core Topics Covered

### 1. Regression & Classification

- **Linear Regression:** Modeling relationships between input features and continuous target variables.
- **Logistic Regression:** Applying probabilistic models to classification tasks.
- **Model Optimization:** Understanding loss functions, gradient-based optimization, and parameter estimation.
- **Model Evaluation:** Assessing predictive performance and generalization.

### 2. Unsupervised Learning & Dimensionality Reduction

- **K-Means Clustering:** Grouping data points into clusters based on feature similarity.
- **Gaussian Mixture Models (GMM):** Modeling data as a mixture of probability distributions using the Expectation-Maximization (EM) algorithm.
- **Principal Component Analysis (PCA):** Reducing dimensionality while preserving as much data variance as possible.
- **Feature Selection:** Identifying informative features to improve model efficiency and performance.

### 3. Neural Networks & Deep Learning

- **Artificial Neural Networks (ANNs):** Understanding neural network architectures, forward propagation, and backpropagation.
- **Convolutional Neural Networks (CNNs):** Learning spatial features from image data using convolutional architectures.
- **Optimization Techniques:** Studying gradient-based learning, loss minimization, and neural network training.

### 4. Natural Language Processing & Transformers

- **Word Embeddings:** Representing words as dense numerical vectors that capture semantic and syntactic relationships.
- **BERT:** Exploring transformer-based language representations and contextual embeddings.
- **Transformer Architectures:** Understanding attention mechanisms and their role in processing sequential data.
- **Text Representation:** Applying embedding-based methods to represent and analyze textual data.

### 5. Practical Machine Learning

- **Algorithm Implementation:** Translating mathematical formulations into working machine learning models.
- **Computational Experiments:** Using Python and Jupyter Notebooks to train models, analyze results, and compare approaches.
- **Theoretical Problem Sets:** Deriving algorithms, analyzing their properties, and studying their mathematical foundations.
